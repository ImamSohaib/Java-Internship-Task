# Java Internship Tasks

A collection of Java console applications developed as part of the Java Programming Internship.

## Repository Structure

- **Task-01:** Bank Account Management System
- **Task-02:** Student Management System
- **Task-03:** File-Based Library Management System
- **Task-04:** Employee Management System


## Task Details & Features

### Task 01: Bank Account Management System
A Java console application demonstrating basic banking operations using Object-Oriented Programming principles.
- **Features:** Account creation, deposit, withdrawal, and balance checking with input validation.
- **Key Concepts:** Encapsulation, Scanner input handling, conditional logic.

### Task 02: Student Management System
A record management system for handling student data using dynamic collections.
- **Features:** Full CRUD (Create, Read, Update, Delete) operations for student records.
- **Key Concepts:** `ArrayList` usage, object manipulation, method modularity.

### Task 03: File-Based Library Management System
A library system that persists book records across application restarts using local file storage.
- **Features:** Add, view, search, issue, and return books with persistent state.
- **Key Concepts:** Java File I/O (`BufferedReader`, `PrintWriter`), serialization, file handling.

### Task 04: Employee Management System
A management system for employee records with multi-field searching capabilities.
- **Features:** Full CRUD operations and multi-attribute search (by name or department).
- **Key Concepts:** Data modeling, defensive programming, exception handling.
